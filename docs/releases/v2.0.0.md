## IPPin 2.0.0 — переход на Rust

IPPin переписан с Go на Rust. Локальный HTTP/HTTPS-прокси проверяет привязанный внешний IP перед допуском запросов и закрывает открытые соединения при провале проверки.

### Изменения

- Один зафиксированный маршрут для проверки IP и полезного трафика; без прямого fallback после отказа выбранного прокси.
- Отмена CONNECT-туннелей и потоковых HTTP/API-ответов при смене IP или недоступной проверке.
- Проверка HTTP CONNECT и SOCKS5, сохранение ранних байтов туннеля, фильтрация служебных заголовков.
- Атомарное сохранение настроек, строгая валидация конфигурации и аутентифицированная остановка фонового процесса.
- Windows PAC с резервной копией прежних настроек и скрытым запуском без наследования дескрипторов.
- Обновлённый CLI: цветные статусы, живые события, справка с быстрым стартом, `--color auto|always|never` и `NO_COLOR`.
- Windows-установщик для AMD64/ARM64 с проверкой SHA256 и обновлением PATH текущего терминала.
- Тесты, Clippy и сборки Windows, Linux и macOS для AMD64/ARM64 в GitHub Actions.

### Установка Windows

```powershell
irm https://raw.githubusercontent.com/chi2l3s/ippin/main/install.ps1 | iex
```

### Переход с Go

1. Старым бинарным файлом выполните `ippin service uninstall` и остановите ручные процессы.
2. Сохраните копию `~/.ippin/config.json`. Имена полей конфигурации сохранены; неправильные значения теперь возвращают ошибку.
3. Установите новую версию, включите VPN, укажите его маршрут и выполните `ippin lock`.
4. Запустите `ippin start` для проверки либо `ippin service install` для Windows-автозапуска.

Изменения `lock`, `mode`, `add` и `remove` применяются после перезапуска. `start -p` меняет порт только текущего процесса. Unix-архивы теперь имеют формат `.tar.gz`; Windows-архивы — `.zip`.

Полная инструкция: [миграция](https://github.com/chi2l3s/ippin/blob/v2.0.0/docs/migration.md).

### Границы защиты

IPPin проверяет только трафик, направленный через него. Измерение IP и отправка данных не атомарны; абсолютный запрет утечек требует сетевых правил ОС/VPN. Подробности: [README](https://github.com/chi2l3s/ippin/blob/v2.0.0/README.md#границы-защиты).
